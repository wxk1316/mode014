# 实车规划、仲裁与控制接口修复说明

日期：2026-11-06。问题快照见《系统框架与问题定位.md》及分段审计；原代码已存 `baseline_sources.zip`。本说明描述最终实现，不把纯 Python 回归当作 ROS2 或实车验收。

## 1. 修复后的闭环

实际启动链仍为 `run_rda_dwa.launch.py → rl_dwa_car.launch.py → lidar_track_node / bridge_node / traj_tracker_node / car_ctr`。顶层 launch 现在透传 `config`，所有节点使用同一 YAML。底盘 launch 显式配置切换等待 3 秒、非幂等模式命令重试间隔 3.5 秒、指令和反馈看门狗 0.3 秒。

规划核心 `VehicleBridgeCore` 负责输入新鲜度、反馈速度、DWA 候选验证、恢复目标与 trap 仲裁；tracker 负责恒频执行、真实模式就绪与航向误差闭环旋转。`/cmd_vel` 保留为诊断兼容接口。执行参考采用 `TwistStamped /rda/command` 与 `Path /rda/traj`，两者共用一次捕获的 `header.stamp`，tracker 只提升完整匹配的新参考，避免新速度与旧路径组合。

模式协议统一为：`/rda/traj_mode=-1` 安全取消并保留当前轮型停车，`0` ACK/零速恢复，`1` 锁存的自转会话；`/car_mode_ready=-1` 未就绪，`0` ACK 就绪，`4` 自转就绪。tracker 结果 `3` 到位、`4` 失败，在停止/恢复期持续发布，低频规划不会漏读。安全取消的 FAULT 不能被重复旧 `1` 重新启动，健康输入及新鲜 `0` 才允许恢复。

## 2. 时间、感知与坐标

定位与障碍物保存消息源 stamp、到达单调时间和到达时源年龄。旧 stamp 的重复发布不刷新新鲜度；有效空检测帧与感知失联明确区分。感知超时、定位超时、模式反馈超时、规划异常/无效指令、当前碰撞、定位跳变均输出停车与明确原因。

TrackManager 只在新输入 revision 时接收量测，不在每次规划时重复差分旧检测。量测锚点单调时刻为 `arrival - source_age`，`snapshot(planning_now)` 把已知速度外推到当前时刻；保留遮挡 track 及不确定性增长由感知 agent 实现。规划消费已有 KF 速度，避免第二层固定 0.1 秒差分把静止/动态判错。

运动朝向 `velocity_heading` 与形状朝向 `shape_heading` 分开。当前 lidar 对所有类型输出 map AABB；`static_obstacle_aabb=true` 是这一源契约的兼容参数名，核心给所有类型补充 shape heading=0，并保存实测尺寸，避免类型尺寸先验/重复方包络填入 U 形空腔。改接其它只含单 heading 的通用 OBB 消息时，应将此参数设 false，由融合层使用保守包络。动态障碍碰撞使用其包围圆，运动方向不会错误旋转检测框。仅首个真实量测时的速度未知通过 `velocity_unknown/max_unknown_speed` 属性传递，过去年龄与未来时域按最大可能速度膨胀；预测重发不算第二次真实量测，确认速度后释放未知上界。

最终用户确认：车长 1.2 m、宽 .8 m、轴距 .69 m，当前 `/localization` 与雷达已经位于车几何中心。因此 `body_to_base_link_x=0`、`footprint_center_offset=0`、`spin_pivot_offset=0`、sensor XY=0，lidar 剔除也以中心为原点；此前 -.15/.15 的假设已撤销。自行车模型显式配置 `reference_center_to_rear=.345`（默认轴对称假定 wheelbase/2，后轴距离尚未单独实测）：先把中心位置转为后轴位置积分，再转回新中心，包含 `centre_y_dot = v*sin(yaw) + h*omega*cos(yaw)` 的横向运动；参考、碰撞与制动统一使用这一模型。定位源年龄对应的可能位移/转动增加到安全裕量，避免把滞后位姿误当作精确当前足迹。

定位连续性有独立锁存门：相邻源时间下位移不能超过物理速度界加 .15 m，航向不能超过自转角速度界加 5°。大坐标/航向跳变触发 `localization_jump`，后续新 stamp 不清除故障、不允许假位移退出 trap 或假 yaw 宣告自转到位。停车重定位后应重启局部链并重新设目标。

## 3. 可执行规划与避障

生产模式只接受 `kinematics_mode=ackermann`，通过独立自转模式扩展恢复能力；raw 4WIS、斜行、平移没有本次控制协议/运动一致性验收。配置拼写错误不会静默回退。最终用户确认支持倒车，生产采样与控制现在统一允许 `v∈[-.3,.4]m/s`，四轮/定位反馈、候选、参考与制动均保留符号；后方障碍同样完整检查。开放环多点掉头 MPT 仍关闭，由正常经过验证的倒车候选或独立自转恢复；不再把负速度截为零。正负换向先制动至零，真实零速保持 .2 秒并由反馈确认后才反向加速，增加速度绝对值用 .5 m/s²、减小用 1.5 m/s²。预测包含这一保持段与 .6 秒可能等待，不能假定立即倒车逃离接近行人。

候选从对称转角空间产生，显式包含直行、停车、反馈转角、历史转角与速度边界；转换为实际可执行角速度并去重。参考预测从反馈速度与当前转角开始，包含加速度/减速度和 45°/s 转角变化限制，不再每周期零速度、零转角冷启动。`w/v` 表达的是完整转角目标，而非下一帧的小转角；bridge 只适配速度，保持完整目标，tracker 与碰撞预测从实际角按同样速率逐步达到该目标。不会再先把 30° 目标压成 4.5° 后把这个小角恒持 3 秒重判，导致看不到后续可行绕行。

所有生产候选在车辆时间与障碍物时间配对的完整 3 秒时域检查，默认步长 .05 秒并检查 t=0。运动间隔采用车辆平移/角点移动与障碍物移动界补偿，防止粗采样穿过障碍。静态矩形使用 SAT 的保守分离下界；动态包围圆按已知速度外推并叠加不确定性。接触/重叠不可行。

预测不可行后不再按障碍当前位置放宽；`ok=False` 不再输出 M6 非零指令。Ackermann 末道适配后的真实 `(v,w)` 再次通过同一安全检查，随后发布这一最新已验证参考，默认禁用未经复查的历史轨迹缓存。

安全检查还验证响应等待、受限减速及停车后足迹，停车后一直检查到完整时域末端，避免动态障碍在制动结束后才接近而被遗漏。`reaction_time=.6s` 覆盖 tracker 0.5 秒参考看门狗及 0.1 秒调度/传输余量。ROS 节点有 .3 秒规划期限，并在发布前检查总源年龄；超预算输出 `planning_deadline_or_input_age`。实际车机需记录 p95/max 耗时并验证该期限可持续满足。

## 4. 平稳性与进展

加入静态局部绕行引导：对已确认静态、处于目标走廊且仍有足够阿克曼转弯距离的障碍，按实际矩形尺寸、车身外接半径和安全裕量生成前/后两个局部 waypoint，锁定绕行侧。DWA 继续验证连接曲线的真实速度/转角变化、完整动态碰撞与制动；waypoint 只是引导，不放宽安全。经过前段再切后段，后段存在安全全局接回曲线才恢复全局目标。动态/未知、已经贴近的障碍不使用该静态引导，必要时走经过验证的倒车或自转。

该引导消除了“直指障碍后的全局目标 → 小速直爬 → 贴近才自转 → 子目标末端再自转”的简单静态死循环。独立按实际 YAML 联跑的静态单块场景已在 18.54 秒到达，最小保守圆净空 .6425 m，无模式切换；一次转角反号对应正常 S 弯回归，最大命令转角变化不超过 45°/s。最终统一回归的结果以主 agent 保存的 `closed_loop_results.json` 为准。

旧归一化把微小速度/转角变化在每次候选窗都放大为满量程惩罚，会造成启动零速与长期 0.05 m/s 爬行。生产评价改为固定物理尺度：

- 时域进展 `(起点目标距离 - 末点目标距离)/(v_max·T)`；
- 速度奖励 `v/v_max`、末端航向误差 `/π`；
- 有界净空奖励和有界风险惩罚；
- 绝对执行平滑惩罚 `(Δv/v_max)² + (Δdelta_next/delta_max)²`，其中 delta_next 为当前转角按速率限制迈出的实际下一步，不对完整长期目标满惩罚；不再对 smooth 做候选 min-max。

停后速度平滑项门控，转角连续性保留。若软评分选择停车，但有完成全部预测/制动验证的正速样本，则允许最佳安全正速推进。安全停车由可行性与输入守卫决定，软代价不会让空地永久停车。

tracker 默认执行已验证的前馈转角，额外纯跟踪修正上限为 0；修正后的纯跟踪索引/实际前视距离计算保留供校准，但把该上限调为正值需要重新检验足迹裕量与执行偏离。转角速率 45°/s、小变化保持 0.25°；加速 .5 m/s²、减速 1.5 m/s²，安全停车不被普通平滑拖延。初次实车复验速度设 .4 m/s，后续可据日志升速，不能只改某一层上限。

## 5. 自转与 trap 防振荡

自转不从 ACK 的 `w` 取速度。进入请求前必须有障碍输入、ACK 保护时间已过、持续真实无有效净位移/目标进展，且新目标角至少偏离车头 10°。有安全微小正负候选不再永久否定自转；正常前进或侧向逃逸的真实进展会刷新窗口，软评分停车本身不被直接当成不可行。空地不会触发自转。

APF 和方向扫描仅提出目标。接受前必须验证停车切模式至少 3 秒、完整车身旋转扫掠、自转减速/安全取消刹停余量、恢复 ACK 至少 3 秒，以及转后第一段 ACK 通行。用户已精确确认 command mode=4、反馈 turnmode=4，而且反馈表示四轮机械到位；launch/CPP 使用 4，旧反馈 mode=2 的假设已修正。自转 UDP -2 倍的符号/比例已由用户实测确认。峰值自转角速度刹停扫掠余量为 `omega²/(2·angular_acceleration)`，验证两侧余量。动态障碍检查覆盖整段等待/旋转/恢复中的车身包围圆，不假定某个理想线性转角时序。没有安全目标时停车等待，不消费次数、不来回切模式。

会话目标由核心选定并锁存；请求期间 ACK `(v,w)=0` 是正确行为，tracker 用锁存目标的 yaw 误差独立产生旋转速度。机械模式 ready 且至少 3 秒后才进入 RUN，RUN 超时从真实开始转起算；必须到位稳定或明确失败后才进入停转/恢复。定位/感知失效或扫掠变危险立即取消。

trap 子目标与逃逸侧在激活时锁存，不每帧随车换根。机械切换与自转期间冻结 trap 推进时间。退出要求至少 .5 m 的真实位移、到达子目标或朝向全局目标，并存在真正减少全局目标距离的安全曲线持续 1 秒；确认期间先安全停车，避免继续围绕已到达子目标来回修正；不再以扇区障碍数量小于 3 宣称清场。超时不清除自转失败次数，配置同一问题最多 2 次、间隔至少 5 秒；新目标或走离问题锚点才重置许可，避免 `trap timeout → spin_used=false → 再自转` 循环。

## 6. 验证与限制

`tests/test_planner_safety.py` 的 44 条回归已通过，覆盖不规则周期的对称/零转角采样、直行、自转前方墙、横穿与完整时域碰撞、真实初态、响应/制动、时间轴异常、足迹偏移、输入过期/重复消息/源年龄、不可行与末道安全闸、启动进展、trap 冻结/真实位移退出、次数保留、定位跳变锁存、明确异常停车，并增加 U 形原始点到核心的集成反例和静态 AABB 几何随机 oracle。

`docs/validation/check_ros_adapters.py` 检查实际 YAML 的声明、读取和构造，最新结果见 `ros_adapter_result.json`。主 agent 的 `run_closed_loop.py` 将实际 YAML 的规划/控制核心与 50 Hz 有界执行器联跑，记录空地、静态绕障、行人横穿的最小净空、转角速率、切换次数与规划耗时；最终结果以 `closed_loop_results.json` 和各 trace 为准。本轮文献依据见 `literature.md`。

本机没有 ROS2/colcon，未接车辆、未发送 UDP，不能声称已通过 DDS、底盘模式反馈或实车性能验收。动态预测仍基于已知速度及有限不确定性界，任意突然奔跑/换向、盲区、速度估计错误与机械标定错误不能由代码测试保证安全。局部 DWA 没有全局路线，复杂死胡同/必须远距离绕行不保证最终到达；有限恢复失败后安全等待是明确行为。后轴相对中心的距离、轮速在阿克曼时的车体速度换算、机械制动/转角响应和全链实时预算仍需实车受控验收。车长宽、中心定位、反馈 mode=4 到位语义与自转 -2 标定已经由用户确认，不再列作未确认事项。

## 7. 连通 U 墙与瓦片几何

一个 U 形墙常被距离聚类连成单簇。把它换成整个簇的一只包围框，会把真实空腔填为障碍，甚至把车心包在碰撞框里。修复后的感知在固定 map 网格上把足够大且稀疏/细长的簇表示为局部 AABB，保存原始点及 voxel 裕量覆盖；小人/实心簇保留整体框。静止瓦片为 block，运动与未知瓦片继承父物体的运动状态，不从瓦片中心变化推导假速度；已确认静态的瓦片继续走矩形碰撞，动态与未知继续走圆包络/速度可达上界。

当前参数为 tile_size=.5 m、extent_threshold=2 m、occupancy_threshold=.5、max_scene_tiles=512；超限明确停止发布并触发输入守卫，不把瓦片粗并成填满空腔的框。感知全周范围为12 m，车体自剔除额外外扩为0，避免把车体边界外的近障碍一起删除。

规划对 shape heading=0 的静态 AABB 使用四条唯一 SAT 轴的闭式投影；与通用 polygon SAT 一样输出保守分离下界，仅作等价几何提速。动态/未知和非零形状朝向仍走原分支。200个随机静态几何 oracle 检查确认不会把精确净空不足的样本误放行。

原始247点 U 形反例（rear x=-1.8 m，两臂 y=±1.3 m，伸至 x=3 m）形成一簇：旧整体框判车心碰撞，新世界瓦片得到26个静态块，车心不碰撞，核心可输出 v=.35 m/s/w=0；实际瓦片核心单步约160 ms（Mac）。原通用 SAT 在26个保守瓦片上约556 ms，闭式路径约112 ms。这些是本机测量，车机仍须检查实时预算。另有近侧壁输入在瓦片处理后仍触发碰撞停车，避免修空腔时放掉真实近障碍。
